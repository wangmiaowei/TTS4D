Interactive 4D viewer

Fly through dynamic and static scenes in real time: move the camera (W/A/S/D, drag), scrub time, change the number of input views, and switch on the uncertainty map.

⏳ Please be patient. Every frame is rendered on a single cloud GPU and relayed through several network hops before it reaches you, so the first frames can take a few seconds and interaction may lag. We are moving the demo to a faster cloud platform.

  • Best experienced on a desktop browser.
  • If the page does not respond, the GPU may be busy — please try again a bit later.
